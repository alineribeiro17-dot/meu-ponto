# Meu Ponto

Aplicativo simples de cartão de ponto (PWA).
A tela fica aqui no GitHub Pages; os dados ficam numa Planilha Google, acessada pelo Google Apps Script.

**Este repositório não guarda dados nem senhas.** O endereço da planilha e a chave de acesso
vão apenas no link pessoal do app e ficam guardados no próprio celular.
